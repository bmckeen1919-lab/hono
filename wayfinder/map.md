# Map — "The Quiet Morning" → Hono

**Label:** `wayfinder:map`
**Tracker:** local-markdown (`wayfinder/`)

## Destination

Translate all **111 sentences** of *The Quiet Morning* (`the_quiet_morning_sentences.csv`) into **Hono** — a language generated by the `conlang` tool and then deliberately extended — and record the result as `the_quiet_morning_hono.csv` with columns `index,english,hono` in this workspace. The agent translates by hand; the generated model is the authority.

## Notes

Effort-specific constraints, settled while charting:

- **Language nature** (Q1b): a **generated core, deliberately extended** — sample a base with the tool, then grow lexicon and grammar to cover the story.
- **Deliverable** (Q2a): the `index,english,hono` CSV only; a gloss column and DOCX are optional later.
- **Home** (Q3a): this dedicated workspace (`C:\Users\bmcke\hono`), mirroring `learn_kah` / `muna` / `volapuk`.
- **Who translates** (Q4a): the agent, by hand; the tool **produces and validates** the language.
- **Name** (Q5a): `hono`, from the sampled root `hono` "sea".
- **Base spec** (Q6a): pin inventory `p t k m n s l r w h` / `a e i o u`, syllables `CV, CVC`, fix the seed; sample morphology and syntax; freeze with `accept`.
- **Lexicon source of truth** (Q7a): the tool's spec/model (`concepts` + pinned `lexicon`); render a readable lexicon from it.
- **Gap policy** (Q8c): **audit first**, decide per gap — default **paraphrase**; extend the tool only for gaps with wide **reach**.
- **Method** (Q9a): English → Hono lookup, verify back, paraphrase with documented strategies, **quarantine** untranslatable items as `[slots]`, normalize dialogue quotes.
- **Workspace** (Q10a): mirror the sibling workspaces (`MISSION`, `NOTES`, `RESOURCES`, `reference/`, `learning-records/`) plus this map.
- **Names** (Q11a): adapt personal names as ordinary roots; **calque/compound** place names where the culture would.
- **Definition of done** (Q12a): 111 rows, one translation each; every form legal under Hono's inventory/phonotactics; consistent gloss→root; `[slots]` marked; checked by a validator.

**Execution:** this effort carries execution into the map — the translation itself, not only decisions — because the destination is the corpus artifact.

Precedents to consult every session: `learn_kah/learning-records/0039-quiet-morning-translation.md`, `muna/translation-gaps.md`, `volapuk/the_quiet_morning_first3_volapuk.csv`.

Six build tickets graduated.
- [Build adpositions, obliques, and place/direction](tickets/feature-adpositions-obliques.md): the tool now generates an invariable `adp` class (20 senses) and clauses take adposition obliques, positioned by word order (VO ⇒ prepositions). - [Build NP modification (adjective, possessive, apposition)](tickets/feature-np-modification.md): `NounPhrase` value accepted by `build_clause` and obliques; modifiers ordered by head direction (VO ⇒ post-nominal), possessive is bare juxtaposition, plus apposition and PP-in-NP. - [Build intransitive (one-argument) clauses](tickets/feature-intransitive-clauses.md): `build_clause` accepts no object; the single argument takes the alignment pivot (accusative ⇒ `NOM`, ergative ⇒ `ABS`); no valency marking; obliques allowed. Model unchanged; **131 tests pass**.
- [Build copula, predicate-adjective, and existential](tickets/feature-copula-existential.md): every language generates a `be` copula (pos `cop`) sharing verb morphology; `build_predication` = subject + copula + bare complement; existential paraphrased as a locative predication. - [Build clause sequencing (parataxis / coordination)](tickets/feature-clause-sequencing.md): generated `conj` class (`and`/`but`/`then`/`so`; `and` moved out of concepts) + `build_sentence` joining clauses by juxtaposition or a connective.
