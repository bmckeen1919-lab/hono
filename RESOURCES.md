# Resources

A living list of high-trust sources. Every claim in the translation should trace
back to one of these. Confidence = how much we verified it ourselves.

## Primary sources

**Hono** — the learner's generated-and-extended language, produced by the
`conlang` toolkit. The translation's authority.
- Frozen spec: `spec/hono.yaml`; model: `out/hono.json`
- Rendered grammar + dictionary: `reference/hono-grammar.md`
- Confidence: high (generated here; lint-valid; reproducible from spec + seed)

**The Quiet Morning** — the fixed 111-sentence English source text.
- Local: `the_quiet_morning_sentences.csv`
- Confidence: high (the source of the translation)

**The `conlang` toolkit (`conlanggen`)** — the generator that produces Hono and
validates its forms (phonotactics, lint, render).
- Repository: <https://github.com/bmckeen1919-lab/conlanggen#readme>
- Confidence: high (source read; commands run)

## Knowledge

**The Language Construction Kit (LCK) — Mark Rosenfelder** — the canonical guide
to phonology, word-building, and grammar; the frame for what a language must
decide.
- <https://www.zompist.com/kit.html>
- Confidence: high

**WALS — World Atlas of Language Structures** — typological reference for word
order, alignment, adposition order, and aspect.
- <https://wals.info/>
- Confidence: high (used to justify the tool's typological defaults)

**r/conlangs wiki: Conlanging Resources** — the community's curated index.
- <https://www.reddit.com/r/conlangs/wiki/resources>
- Confidence: high
