# Learning Record 0001 — the Hono translation project begins

**Date:** 2026-10-05
**Status:** Accepted

## Context

*The Quiet Morning* (111 sentences) is translated into several constructed
languages — Kah, Muna, Volapük — as a fixed expressive test. Hono is a new
language generated by the `conlang` toolkit. This project adds Hono to that set,
and the route was charted as a wayfinding map (`wayfinder/map.md`).

## Decision / Insight

**Hono is the tool's model, generated then deliberately extended — and the
translation is by hand against that model as the authority.** A seeded base
(inventory `p t k m n s l r w h` / `a e i o u`, syllables `CV, CVC`) is frozen
with `accept`; the lexicon and grammar are grown only as the story demands. Code
changes to the toolkit are a means to that end (six syntax builds shipped), not
the goal.

## Consequences

- The map's syntax layer is closed: adpositions, noun phrases, intransitive
  clauses, copula, clause sequencing, and aspect are all built and the tool is
  committed (`conlanggen`).
- Remaining frontier: `design-lexicon`, `translation-method-and-slots`,
  `csv-validator`, then the translation batches.
- **Hono's morphology is pinned in the frozen spec** — a future toolkit change to
  affixes must be pushed through by re-deriving the affix list, not a plain
  regenerate.
- The 111-row CSV is the definition of done; gaps are logged, not hidden.

## Verification

- Model `out/hono.json`: 199 lexemes, 1409 word forms, lint `valid`; spec
  `spec/hono.yaml` reproduces it.
- The toolkit's suite: 147 tests pass; golden digests locked.
- Charting constraints recorded in `NOTES.md` (Q1–Q12) and `wayfinder/map.md`.
