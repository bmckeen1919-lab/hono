# Hono — glossary

Shared vocabulary for this project. Load-bearing across the map, the tickets,
and the translation. (The tool's own terms — **spec**, **model**, **seed**,
**freeze** — are defined in `C:\Users\bmcke\conlang\CONTEXT.md`.)

| Term | Meaning |
| --- | --- |
| **Reach** | The number of the 111 sentences a grammar gap touches. A coverage count, not a cost estimate; it ranks gaps. |
| **Structural gap** | A missing *construction* that blocks whole classes of sentence — as opposed to a **lexical gap**, a missing word. |
| **Paraphrase** | Covering a construction the language lacks by recasting it with what the language has. Preferred over building machinery (Q8c). |
| **Parataxis** | Joining clauses by sequence/juxtaposition instead of embedding. The route we chose for relatives, reported speech, and coordination (Q3a). |
| **Predication tier** | The base grammar being added to the tool: intransitive clauses, copula / predicate-adjective / existential, adpositions & obliques, NP modification, clause sequencing. |
| **Aspect tier** | The verb layer added alongside past/future: progressive, perfect, pluperfect. |
| **Slot** | An untranslatable item quarantined as `[slot]` at translation time rather than fudged (Q9a). |
| **Misdiagnosed gap** | A construction that *looks* like missing machinery but is already expressible by paraphrase — e.g. passive, relatives, reported speech (Q3a). |
